
一、最重要的辅音组合（8 条 ⭐⭐⭐⭐⭐）

2. sh → /ʃ/  she, ship

3. th → /θ/ /ð/  think / this

4. ph → /f/  phone

5. ck → /k/  back

6. ng → /ŋ/  king, long

7. wh → /w/  what, where

8. qu → /kw/  quick, question
