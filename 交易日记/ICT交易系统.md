# 市场定义工具与 PD Array 笔记

> 核心原则：先确定交易区间与外部流动性目标，再用 PD Array 找回踩区，最后用小周期结构和 SMT 做进场确认。  
> PD Array 不是单独的买卖信号，必须结合位置、流动性和结构。

## 一、交易区间（Trading Range）

### 定义

由一段完整价格冲击中的高点和低点构成的价格波动范围。

### 划分方法

- 以一整段冲击过程为单位；
    
- 找到完整区域的高点、低点；
    
- 重点观察区间两端是否出现上下双扫；
    
- 区间内部用于判断内部流动性，区间外部用于判断目标流动性。
    

### 区间工具

- **Premium / Discount（溢价与折扣）**
    
    - 区间上半部：溢价区，优先观察卖出机会；
        
    - 区间下半部：折扣区，优先观察买入机会。
        
- **OTE**
    
    - 用于在回调过程中寻找较优入场区；
        
    - 不能脱离 HTF 方向和流动性目标单独使用。
        

---

## 二、流动性（Liquidity）

### 内部流动性

当前交易区间内部的 PDA、局部高低点和短线止损聚集区。

### 外部流动性

- 当前区间的高点或低点；
    
- 更大周期区间的 PDA；
    
- 前日高低点、时段高低点、明显等高/等低等。
    

### 使用逻辑

> 价格往往先处理内部流动性，再奔向外部流动性。  
> 交易前先问：当前价格最可能去拿哪一侧的流动性？

---

## 三、SMT（Smart Money Technique）

### 定义

两个相关品种、或两个相关市场，在关键高低点出现不一致：

- 一个创新高，另一个没有创新高：偏看跌 SMT；
    
- 一个创新低，另一个没有创新低：偏看涨 SMT。
    

### 注意

- 任何高低点都有可能形成 SMT；
    
- 不一定非要大周期、也不一定非要盘前盘后；
    
- SMT 是确认与筛选工具，不是单独的进场理由。
    

### 常见出现位置

- **PO3 转折点**：留意前一根关键蜡烛；
    
- **时段极值点**：亚洲、伦敦、纽约的高低点；
    
- **FVG 内的二次进场**：
    
    - 第一次回踩 FVG，先观察缺口反应；
        
    - 价格进入 FVG 后，再观察 1m SMT；
        
- **Breaker / IFVG 回踩**；
    
- **盘整中的三驱动**：连续多次 SMT 可能提示扫流动性后的转向。
    

### 周期用途
![](assets/ICT交易系统/file-20260814195627820.png)
![](assets/ICT交易系统/file-20260814195723339.png)

| SMT 周期  | 主要用途           |
| ------- | -------------- |
| 15m 及以上 | 确认较大级别反转模型     |
| 1m      | 捕捉反转刚发生时的精确确认  |
| 3m / 5m | 趋势启动后的第一次浅回调机会 |
| 15m     | 趋势启动后的较深回调机会   |

---

## 四、FVG（公平价值缺口）

### 定义

价格快速推动时形成的三根 K 线不平衡区。它通常是回踩、补价、延续或反转时的重要 PDA。

### 普通 FVG 的用途

- 多头 FVG：回踩后守住，偏多；
    
- 空头 FVG：反抽后受压，偏空；
    
- 先看它位于 Premium 还是 Discount，再判断是否值得交易。
    

### 课程笔记：FVG 的形态方向

|   |   |
|---|---|
|形态|课程内含义|
|AAA（3 根同向）|强力传递，可能形成 Breakaway|
|BAA（后 2 根同向）|反转后的动能，突破回踩区，可能形成 OB|
|AAB（前 2 根同向）|接近趋势传递末端，可能出现较大回踩|
|BAB（第 1、3 根同向）|长实体时可能是盘整、无效或频繁穿插；短实体/影线时可能形成 PB|

> 上表是这套课程的分类语言，不是所有 ICT/SMC 交易者的统一标准；实际仍要看结构、位置与流动性。

### FVG 入场

- **1m**：观察 FVG 是否被 tap（回踩触及），以及是否属于 breakaway；
    
- **15m 及以上**：可重点看 CE（Consequent Encroachment，缺口中线）附近的反应或挂单；
    
- 进场前最好有扫流动性、CHoCH/MSS 或 SMT 确认。
    

---

## 五、IFVG（反转公平价值缺口）

### 定义

原本的 FVG 被价格有效打穿后，区域角色反转。

- 多头 FVG 被跌破 → 回踩后变为空头 IFVG / 压力；
    
- 空头 FVG 被突破 → 回踩后变为多头 IFVG / 支撑。
    

### 小周期执行笔记

|   |   |
|---|---|
|周期|处理方式|
|1m / 2m|结构、流动性和确认齐全时，可考虑直接市价执行|
|3m / 5m|优先等待蜡烛实体约一半位置、回踩或结构确认|
|1H 以上发生流动性清扫|小周期 IFVG 的质量通常更高|

> IFVG 的价值在于“原方向失败后，角色反转”。必须等有效收盘打穿，影线短暂刺破不算。

---

## 六、OB / Breaker / PB / Rejection

### OB（Order Block，订单块）

- OB 是一个区域，不是一条精确价格线；
    
- 重点观察 **OBMT / OB 中线附近**，不要把整个 OB 都当成同等强度；
    
- 高质量 OB 常配合前方强力扩张、扫流动性和结构突破。
    

### PB（Pullback，回调）

- 回调要配合前方的强力扩张；
    
- 没有位移、没有结构确认的回调，不自动等于机会。
    

### Breaker（突破块）

- 可与 FVG 组合，形成 Unicorn 模型；
    
- 在 MMXM 中，有时会出现突破后对原止损区的猎杀；
    
- 回踩 Breaker 时，仍需观察 SMT、结构与流动性方向。
    

### Rejection（拒绝区）

- 由瞬间强力反应形成；
    
- 在盘整、趋势通道回踩中可作为观察区；
    
- 不能只看长影线就反向交易，要等待收盘与结构确认。
    

---

## 七、ViB / 开盘缺口类工具

### NWOG

- New Week Opening Gap；
    
- 课程笔记：保留约 3 周。
    

### NDOG

- New Day Opening Gap；
    
- 课程笔记：保留约 1 周。
    

### ORG

- Opening Range Gap；
    
- 课程笔记：长期保留。
    

### 使用方式

- 缺口可分为 4 等分；
    
- 价格在填补过程中，每个分位都可能出现反应或回调；
    
- 结合开盘后第一根 15m K 线判断当日方向；
    
- 开盘若不填补或仅小幅填补，可能直接反转，也可能在清扫外部流动性后才回来填补；
    
- 不要预设“缺口一定会被填补”。

## 八、我的 15 分钟黄金执行顺序

1. **1H / 4H**：标出交易区间、外部流动性、HTF FVG / OB / IFVG；
    
2. **15m**：判断价格在溢价还是折扣、当前目标流动性在哪一边；
    
3. **等价格到 HTF PDA**：例如 FVG、IFVG、OB、Breaker、BPR；
    
4. **5m**：等待扫流动性 + CHoCH/MSS；
    
5. **1m / 3m**：用 SMT、FVG 或 IFVG 回踩精确进场；
    
6. **止损**：放在被扫高低点之外；
    
7. **目标**：优先看内部流动性，再看外部流动性。
    

> 不做的情况：价格在区间中间、没有明确流动性目标、没有结构确认、只有一个单独 FVG/OB 信号。


## 九、STDV：标准差与位置

### 核心逻辑

当**流动性、PDA 与 STDV 区间高度重叠**时，价格出现反应的概率会提高。

### 课程内的 STDV 区域

|STDV 区间|可能反应|
|---|---|
|-1 / -1.5|可能触发回调|
|-2 / -2.5|可能触发回调或反转|
|-3.5 / -4|可能触发更明显的反转|

> STDV 只说明价格相对均值的延伸程度，不代表碰到某个数值就必然反转。最好同时有外部流动性、HTF PDA、扫流动性和结构确认。

### 课程内的观察周期

- 小时级别：看 `1m`
    
- 日线级别：看 `5m / 15m`
    
- 周线级别：看 `1H / 4H`

## 十、市场结构

### 趋势由什么决定

#### 1. 速度

- 有明显的 **Displacement（位移）**
    
- 位移后最好产生 FVG
    
- 越是快速、连续、强实体推动，趋势传递越强。
    

#### 2. 幅度与收盘

- 看价格的**实体传递**，不只看影线；
    
- 强趋势通常表现为：收盘持续向趋势方向推进，反向影线较短；
    
- 单纯影线刺破，不能等同于有效突破。
    

#### 3. 高低点结构

|   |   |
|---|---|
|结构|定义|
|上涨趋势|更高的高点（HH）+ 更高的低点（HL）|
|下跌趋势|更低的低点（LL）+ 更低的高点（LH）|

---

## 十一、反转确认：MSS、CISD、IFVG

### MSS：Market Structure Shift

**定义：** 蜡烛强力突破中期高点或中期低点，说明市场结构开始改变。

高质量 MSS 的条件：

- 实体收盘有效突破；
    
- 最好有强位移；
    
- 最好产生 FVG；
    
- 突破的是中期高低点，而不是无意义的小波动点。
    

### 中期高点 / 低点如何找

- 两个高点之间形成的波段低点；
    
- 两个低点之间形成的波段高点；
    
- 获取流动性之前，最后一段传递形成的关键波段高低点。
    

### CISD：Change in State of Delivery

**定义：** 蜡烛强力反转 OB，价格交付状态由原方向转为反方向。

重点：

- 中间不能出现反向蜡烛收盘；
    
- 它是较早的“交付方向改变”提示；
    
- CISD 不如 MSS 严格，因此最好再等 MSS、FVG 或回踩确认。 
    

### IFVG：Inverse Fair Value Gap

**定义：** 蜡烛强力突破反向 FVG，原本 FVG 的支撑/阻力角色反转。

高质量 IFVG：

- 蜡烛实体直接突破反向 FVG；
    
- 最好没有明显影线回踩；
    
- 突破后回踩 IFVG 并配合 SMT、MSS，可作为进场观察区。
    

---

## 十二、反转模型的简化顺序

> 外部流动性 / STDV 极端区 + HTF PDA  
> → 扫流动性  
> → CISD 或 MSS  
> → 产生 FVG / IFVG  
> → 回踩 FVG、IFVG、OB 或 Breaker  
> → 小周期 SMT 确认  
> → 进场

### 不做反转的情况

- 只碰到 STDV 极端区，但没有扫流动性；
    
- 只有影线刺破，没有实体收盘确认；
    
- 没有 MSS / CISD；
    
- 在交易区间中间位置；
    
- 进场后没有清晰的外部流动性目标。
